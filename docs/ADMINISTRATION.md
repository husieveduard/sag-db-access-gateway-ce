# Адміністратори SAG CE — web management (test branch)

У розділі **Адміністратори** локальний Superadmin може:

- створити локального адміністратора через форму `+ Додати адміністратора`;
- призначити при створенні `admin` або `superadmin`;
- змінювати роль існуючих локальних або доменних адміністраторів;
- вимкнути або активувати обліковий запис.

Кожна зміна ролі, стану та створення облікового запису записується в `audit_events`.
Паролі з форми не зберігаються в audit. Пароль передається користувачу через захищений канал.
Перший вебвхід локального адміністратора вимагає TOTP MFA (QR + recovery codes).

Важливі обмеження:
- лише Superadmin може керувати іншими адміністраторами;
- останній активний Superadmin не може бути понижений або вимкнений;
- Superadmin не може вимкнути власний обліковий запис через вебформу;
- облікові записи AD з'являються лише після успішного входу через дозволену групу AD. Їхній пароль у SAG не встановлюється;
- CLI `sag:ce-create-admin` зберігається як аварійний механізм створення локального адміністратора;
- CLI `sag:ce-set-password <email>` підтримує активних локальних `admin` і `superadmin`.

Після оновлення Docker-образів та перевірок відвідай `/admin/administrators`. Нових міграцій не потрібно.
Поточний бранч є тестовим, без змін `main`.
