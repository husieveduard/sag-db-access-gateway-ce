# SAG DB Access Gateway CE — Public Scope

## Included
- PostgreSQL gateway
- MySQL gateway
- experimental MSSQL gateway
- temporary, persistent and service DB sessions
- source IP/CIDR restrictions
- DB connection and SQL audit
- SQL risk classification
- local users and roles
- manual termination
- Docker Compose runtime

## Excluded
- SSH, RDP, web access and Guacamole
- MFA
- approval workflow
- LDAP, Active Directory and SSO
- Vault
- Incident Manager
- proprietary integrations
- internal infrastructure settings
